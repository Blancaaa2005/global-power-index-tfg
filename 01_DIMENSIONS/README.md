# Global Power Index – Dimensions

This directory contains the eight dimensions used
to measure the global power of the five selected countries.

## Dimensions

1. Economic Capacity
2. Military Capacity
3. Cultural Influence
4. Diplomatic Influence
5. Future Resources
6. Defense Networks
7. Economic Relations
8. Resilience

Countries: USA, CHN, JPN, RUS, IND.

Historical period: 2006–2025.
